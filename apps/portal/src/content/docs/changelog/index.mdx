<ChangelogEntry client:only="react" title="Text level 4 retired in favor of text level 3 (UUI-4439)" startDate="Nov 3, 2026" status="migrating" version="1.6.2">

`foreground-4` / `text-cn-4` is no longer used anywhere in the design system. Disabled states are expressed with the 60% disabled opacity rather than a dedicated text color, so the extra gray level was redundant.

Every `text-cn-4` and `foreground-4` usage, plus the `--cn-text-4` placeholder, drawer and breadcrumb styles, now uses `text-3` (`foreground-3`), and `text-cn-disabled` now resolves to `text-3`. Visual change: disabled placeholders now share the enabled placeholder color, with opacity alone marking them disabled.

`foreground-4` remains in the `Text` and `Shimmer` types so existing code still compiles, but it is deprecated and an ESLint rule now errors on `color="foreground-4"`. Migrate to `foreground-3`; the option will be removed in a later release.

Docs and foundations no longer list text level 4.

</ChangelogEntry>

<ChangelogEntry client:only="react" title="Bold code typography variants" startDate="Nov 2, 2026" endDate="Nov 2, 2026" status="released" version="1.6.1">

Added `body-code-strong` and `caption-code-strong`: bold (mono `700`) counterparts of `body-code` and `caption-code`, with the same size and line-height.

Available as `<Text variant="body-code-strong" />` / `<Text variant="caption-code-strong" />` and the `.font-body-code-strong` / `.font-caption-code-strong` utilities, backed by the new `--cn-body-code-strong` and `--cn-caption-code-strong` tokens.

Use them in place of raw bold weights on monospaced text.

</ChangelogEntry>

<ChangelogEntry client:only="react" title="Font weight buckets renamed and retired (UUI-4416)" startDate="Nov 2, 2026" endDate="Nov 2, 2026" status="released" version="1.6.0">

The `heading` weight bucket is now **`500`** (optical 500, "Medium"), so every bucket name matches the weight it renders.

**Breaking:** `--cn-font-weight-default-normal-heading` is now `--cn-font-weight-default-normal-500`.

The unused `600` bucket (optical 530) and the deprecated `500` bucket (optical 440) are removed; `--cn-font-weight-default-normal-600` no longer exists.

The light and bold weights are removed as well: the `300` and `700` buckets (and mono `300`), the `body-light` and `caption-light` typography variants (`<Text>` variants, `.font-*` utilities, and their lint rule), while mono `700` (Bold) stays.

Use `body-normal` / `caption-normal` instead of the light variants. Other `.font-*` utilities and `<Text>` variants are unaffected.

</ChangelogEntry>

<ChangelogEntry client:only="react" title="Semibold weights migrated to the heading weight (UUI-4286)" startDate="Oct 23, 2026" endDate="Oct 23, 2026" status="released" version="1.5.5">

Every typographic style that previously rendered **Semibold (optical 530)** now renders at the **`heading` weight (optical 500, "Medium")** — lighter and more balanced while keeping clear hierarchy over body text.

This covers the `-strong` body and caption styles (`body-strong`, `body-single-line-strong`, `caption-strong`), `micro-normal`, small links, dialog titles, emphasized and heading markdown, chart values, and the Avatar, Stepper, Drawer, and Sheet titles.

Nothing needs to change in consuming code — the `.font-*` utilities and `<Text>` variants resolve to the new weight automatically.

The `600` bucket (optical `530`) is **no longer used** anywhere in the library. It remains defined for backwards-compatibility, and a follow-up will retire it — along with the other deprecated weight buckets — once remaining direct consumers migrate.

</ChangelogEntry>

<ChangelogEntry client:only="react" title="Typography weight normalization (UUI-3467)" startDate="Oct 7, 2026" endDate="Oct 30, 2026" status="migrating" version="1.4.0">

The typography scale has been normalized to two optical weights: **Regular (400)** and **Semibold (600, which renders at optical 530)** for Inter, while JetBrains Mono keeps **Regular** and **Bold**. The in-between weights are no longer part of the recommended scale, and every `.font-*` utility and `<Text>` variant now resolves to one of these normalized weights.

The previous **light (300)**, **medium (500)**, and **bold (700)** weights have **not been removed** — they are retained for backwards-compatibility and are now marked **deprecated** across every layer of the system: the `caption-light` Text variant, the `.font-body-light` and `.font-caption-light` utilities, the `body.light` and `caption.light` composite tokens, and the underlying weight primitives (Inter `300 / 500 / 700`, JetBrains Mono `300 / 500`).

Existing usage keeps working and the deprecated specimens remain on the [Typography foundations](/foundations/typography/) page for reference.

New adoption is blocked by an ESLint rule — migrate to the `-normal` / `-strong` siblings instead.

**Timeline — started October 7, 2026 · due October 30, 2026.** Teams should complete migration off the deprecated weights to the `-normal` / `-strong` siblings before this date.

</ChangelogEntry>
