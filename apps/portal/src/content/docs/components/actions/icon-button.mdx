An icon button is the `Button` component rendered with only an icon and no text label. Set the `iconOnly` prop to optimize the button's styling for a single icon.

Because an icon button has no visible label, you must provide `tooltipProps` so the action stays accessible. If you intentionally want to skip the tooltip, set `ignoreIconOnlyTooltip`.

## Default Icon Button

</div>`}

## Usage

```tsx
import { Button, IconV2 } from '@harnessio/ui/components'

// Icon only button — provide tooltipProps for accessibility
<Button iconOnly tooltipProps={{ content: 'Add' }}>
  <IconV2 name="plus" />
</Button>

// Skip the tooltip explicitly
<Button variant="secondary" size="sm" iconOnly ignoreIconOnlyTooltip>
  <IconV2 name="git-branch" />
</Button>

// The 2xs and 3xs sizes set iconOnly automatically
<Button variant="outline" size="2xs" ignoreIconOnlyTooltip>
  <IconV2 name="check" />
</Button>
```

## Variants and Sizes

Icon buttons support the same variants and sizes as a regular `Button`. The `2xs` and `3xs` sizes enable `iconOnly` automatically.

## AI Icon Button

The `ai` variant pairs with `iconOnly` for AI-related actions, including the automatic loading state from a promise `onClick`.

<DocsPage.ComponentExample
  client:only
  code={`<div className="space-y-cn-sm">
  <div className="flex items-center gap-cn-md">
    <span className="text-cn-size-2 text-cn-3 w-32 shrink-0 font-mono">ai</span>
    <Button
      iconOnly
      variant="ai"
      tooltipProps={{ content: "Ask AI" }}
      onClick={async () => {
        await new Promise(resolve => setTimeout(resolve, 1000))
      }}
    >
      <IconV2 name="ai-solid" skipSize />
    </Button>
  </div>
</div>`}
/>
