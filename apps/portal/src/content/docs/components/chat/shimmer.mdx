The `Shimmer` component animates a sweep of light across text, most often to signal that content is still generating in AI and chat interfaces. It wraps a single string of text and renders it as any element you choose.

<DocsPage.ComponentExample
  client:only
  code={`<Shimmer>Loading response...</Shimmer>`}
/>

## Variations

### With different duration

Control the animation speed with the `duration` prop (in seconds).

<DocsPage.ComponentExample
  client:only
  code={`<div className="flex flex-col gap-cn-md">
  <Shimmer duration={1}>Fast shimmer (1s)</Shimmer>
  <Shimmer duration={2}>Default shimmer (2s)</Shimmer>
  <Shimmer duration={4}>Slow shimmer (4s)</Shimmer>
</div>`}
/>

### With different spread

The `spread` prop controls the width of the shimmer highlight (multiplied by the text length). Higher values create a wider band of light.

<DocsPage.ComponentExample
  client:only
  code={`<div className="flex flex-col gap-cn-md">
  <Shimmer spread={1}>Narrow spread</Shimmer>
  <Shimmer spread={2}>Default spread</Shimmer>
  <Shimmer spread={4}>Wide spread</Shimmer>
</div>`}
/>

### With different colors

Use the `color` prop to change the shimmer text color. It uses the same color tokens as the `Text` component.

<DocsPage.ComponentExample
  client:only
  code={`<div className="flex flex-col gap-cn-md">
  <Shimmer color="foreground-1">Foreground 1</Shimmer>
  <Shimmer color="foreground-2">Foreground 2 (default)</Shimmer>
  <Shimmer color="foreground-3">Foreground 3</Shimmer>
  <Shimmer color="brand">Brand color</Shimmer>
  <Shimmer color="success">Success color</Shimmer>
</div>`}
/>

### Custom element type

Use the `as` prop to render the shimmer as a different HTML element.

<DocsPage.ComponentExample
  client:only
  code={`<div className="flex flex-col gap-cn-md">
  <Shimmer as="span">Span element</Shimmer>
  <Shimmer as="h3" className="text-xl font-semibold">Heading element</Shimmer>
  <Shimmer as="div">Div element</Shimmer>
</div>`}
/>

## Installation

```typescript jsx
import { Shimmer } from '@harnessio/ui/components'

// Basic usage
<Shimmer>Generating response...</Shimmer>

// With custom color
<Shimmer color="foreground-1">
  Processing your request...
</Shimmer>

// With custom duration and spread
<Shimmer duration={3} spread={3} color="brand">
  Loading...
</Shimmer>

// As a different element
<Shimmer as="h2" variant="heading-base">
  Loading title...
</Shimmer>
```

## Anatomy

`Shimmer` renders a single line of text (passed as `children`) inside a `<p>` by default, with an infinitely-repeating gradient sweep. It takes the same typographic `variant` and `color` tokens as `Text`, so it slots in wherever a piece of text would go.

```tsx
<Shimmer>Generating response...</Shimmer>
```

- **`children`** must be a plain string — the component measures its length to size the shimmer band, so it can't wrap arbitrary nodes.
- **`as`** swaps the rendered element (`p` by default) — use `span` inline, or a heading element for a loading title.
- **`variant`** and **`color`** match the `Text` component's typography and color tokens, so the shimmering text lines up with the real text it stands in for.

## Best practices

{/* TODO: editorial — please review against product guidance. */}

**Do**

- Reach for `Shimmer` on short, transient labels — "Thinking…", "Generating response…" — while a model is working.
- Match the `variant` and `color` to the text that will replace it, so the swap-in doesn't shift the layout.
- Swap the shimmer for the real content as soon as it's ready; it's a waiting state, not a decoration.

**Don't**

- Don't use it for long passages or multi-line blocks — it's tuned for a single short string.
- Don't leave it running indefinitely; if a request stalls, show an error or retry instead of an endless shimmer.

## Content

{/* TODO: editorial — please review against product guidance. */}

- Keep the text short and in the present tense while active ("Analyzing…", "Loading…").
- Prefer a specific label ("Reviewing your code…") over a generic "Loading…" when you know what's happening.

## Accessibility

### Labeling

- `Shimmer` renders ordinary text, so its content is read normally by screen readers. If it marks a region that's actively updating, consider placing it inside an `aria-live` region so the eventual result is announced.

### Focus & states

- The effect is purely visual (an animated background sweep) and adds no roles or interactivity. The animation loops continuously while mounted; unmount it once the real content arrives.
