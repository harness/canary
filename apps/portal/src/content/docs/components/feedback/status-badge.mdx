### Variants

The `StatusBadge` component supports different visual variants, including `primary` (default), `secondary`, `outline`, `ghost`, and `status`.

- The `status` variant supports an optional `pulse` prop for animated status indication.
- For all other variants, the `pulse` prop is not allowed.

## Anatomy

`StatusBadge` is a single, self-contained element — a small pill wrapping its text `children`, with an optional leading `icon` (non-status variants) or a pulsing status dot (the `status` variant).

```typescript jsx
<StatusBadge variant="status" theme="success" pulse>
  Online
</StatusBadge>
```

- **`variant`** sets the visual treatment (`primary`, `secondary`, `outline`, `ghost`, `status`).
- **`theme`** sets the color (`muted` by default).
- **`icon`** and **`pulse`** are mutually exclusive by variant: `icon` is available on every variant except `status`, and `pulse` is available only on `status`.

## Best practices

{/* TODO: editorial — please review against product guidance. */}

**Do**

- Keep the label short — a word or two — so the badge stays compact and scannable.
- Match the `theme` to the meaning (`success`, `warning`, `danger`, …) so color reinforces the text.
- Use the `status` variant with `pulse` for live/real-time states (online, running); use the other variants for static labels.

**Don't**

- Don't use `StatusBadge` for anything clickable — it's read-only. Use a button or link for actions.
- Don't rely on color alone to carry meaning; the text should stand on its own.

## Content

{/* TODO: editorial — please review against product guidance. */}

- Prefer a single clear state word ("Success", "Failed", "Running") over full sentences.
- Use consistent capitalization across a set of badges.

## Accessibility

### Labeling

- The badge's meaning comes from its visible text `children`, so always provide a clear label rather than relying on theme color alone.
- The pulsing status dot is decorative (`aria-hidden`) and adds no text for assistive tech — the label must convey the state.

### Focus & states

- `StatusBadge` is non-interactive: it renders a plain element with no role, tab stop, or click handling, so it isn't focusable and isn't announced as a control.
