The `Radio` component lets people choose a single option from a set. It's a compound component: `Radio.Root` provides the group context and manages selection, and each `Radio.Item` is a selectable option. `Radio.Item` must always be used inside a `Radio.Root`.

<DocsPage.ComponentExample
  client:only
  code={`() => {
    const [group1Value, setGroup1Value] = React.useState('option1');

    return (
      <Layout.Vertical gap="xl" className="min-w-[400px]">
        <Radio.Root
            value={group1Value}
            onValueChange={setGroup1Value}
            label="Standard usage"
            caption="Caption text"
          >
          <Radio.Item value="option1" label="Option 1" caption="This is option 1" />
          <Radio.Item value="option2" label="Option 2" caption="This is option 2" />
          <Radio.Item value="option3" label="Option 3" caption="This is option 3" />
        </Radio.Root>
      </Layout.Vertical>
    );

}`}
/>

## Variations

### Optional

The radio group can be marked as optional via the `optional` prop on `Radio.Root`.

If the `Radio.Root` has a label, the optional indicator will appear next to the label.

If there's no label, the optional indicator will be shown next to each individual radio item.

<DocsPage.ComponentExample
  client:only
  code={`() => {
    const [group1Value, setGroup1Value] = React.useState('option1');

      return (
        <Layout.Vertical gap="xl" className="min-w-[400px]">
            <Radio.Root
              value={group1Value}
              onValueChange={setGroup1Value}
              label="Optional usage with group label"
              optional
            >
              <Radio.Item value="option1" label="Option 1" caption="Caption text" />
          </Radio.Root>
          <Separator />
          <Radio.Root
              value={group1Value}
              onValueChange={setGroup1Value}
              optional
            >
              <Radio.Item value="option1" label="Option 1" caption="Caption text" />
          </Radio.Root>
        </Layout.Vertical>
      );

}`}
/>

### Disabled

The radio group can be marked as disabled via the `disabled` prop on `Radio.Root`, which disables all radio items within the group.

Alternatively, the `disabled` prop can be passed to individual `Radio.Item` to disable them selectively.

### Orientation

The `Radio.Root` component accepts an optional `orientation` prop, which defines the layout direction of the radio and its group label.
Available options are `horizontal` and `vertical` (default).

## Anatomy

`Radio` is a compound component built on Radix UI's radio group. Wrap the options in `Radio.Root` and render one `Radio.Item` per choice.

```tsx
<Radio.Root value={value} onValueChange={setValue} label="Label text">
  <Radio.Item value="option1" label="Option 1" caption="This is option 1" />
  <Radio.Item value="option2" label="Option 2" caption="This is option 2" />
</Radio.Root>
```

- **`Radio.Root`** — the group container and context. Control the selection with `value` + `onValueChange` (or leave it uncontrolled with `defaultValue`). It also carries the group-level `label`, `caption`, `optional`, `error`, `disabled`, `orientation`, and tooltip.
- **`Radio.Item`** — a single option. `value` is required; `label` and `caption` describe it. An item is disabled when its own `disabled` is set or the group is disabled.

## Best practices

{/* TODO: editorial — please review against product guidance. */}

**Do**

- Use radios when there are a few mutually exclusive options that are all worth showing at once; use a select when the list is long.
- Give the group a `label`, and keep each item label short with an optional `caption` for detail.
- Preselect a sensible default when one exists, so people aren't forced to make a choice they don't care about.

**Don't**

- Don't use a radio group for a single on/off choice — use a checkbox or switch.
- Don't disable the whole group to communicate an error; use the `error` state and keep the options readable.

## Content

{/* TODO: editorial — please review against product guidance. */}

- Write item labels as parallel, self-contained phrases ("Everyone", "Only me").
- Use `caption` for the consequence or detail of an option, not to restate the label.

## Accessibility

### Keyboard

- Built on Radix's radio group: `Tab` moves focus into the group, and the arrow keys move the selection between items. Only the selected item (or the first item, if none is selected) is in the tab order.

### Labeling

- Each item's `label` is wired to its input via `htmlFor` / `id`, so clicking the label selects the item. If you omit `label`, provide an accessible name yourself.
- The group exposes `radiogroup` semantics and items expose `radio`, courtesy of Radix.

### Focus & states

- The `error` prop toggles the group's error styling; it does not, on its own, detect whether an item is selected. Drive it from your own validation.

  disabled?: boolean;
  iconProps?: IconPropsV2;
}
