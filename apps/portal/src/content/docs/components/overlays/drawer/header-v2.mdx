`Drawer.HeaderV2` is a structured, opinionated header that consolidates icon/logo, title, description, actions, metadata (children), and tabs into a single component. It replaces the compositional pattern of `Drawer.Header` > `Drawer.Title` > `Drawer.Description` when you want a standardized layout with optional loading state.

## Basic

<DocsPage.ComponentExample
  client:only
  code={`
    <Drawer.Root>
      <Drawer.Trigger>
        <Button>Open Drawer with HeaderV2</Button>
      </Drawer.Trigger>

      <Drawer.Content size="md">
        <Drawer.HeaderV2
          title="Pipeline Settings"
          description="Configure your pipeline execution settings"
          icon="settings"
        />
        <Drawer.Body>
          <p>Drawer body content goes here.</p>
        </Drawer.Body>
        <Drawer.Footer>
          <ButtonLayout.Root>
            <ButtonLayout.Primary>
              <Button>Save</Button>
            </ButtonLayout.Primary>
            <ButtonLayout.Secondary>
              <Drawer.Close asChild>
                <Button variant="outline">Cancel</Button>
              </Drawer.Close>
            </ButtonLayout.Secondary>
          </ButtonLayout.Root>
        </Drawer.Footer>
      </Drawer.Content>
    </Drawer.Root>

`}
/>

## With tabs

Wrap the drawer content in a `Tabs.Root` to enable tab switching. `Drawer.HeaderV2` renders the tab strip at the bottom of the header when `tabs` is provided.

<DocsPage.ComponentExample
  client:only
  code={`() => {
    const [tab, setTab] = React.useState('overview');

    return (
      <Drawer.Root>
        <Drawer.Trigger>
          <Button>HeaderV2 with Tabs</Button>
        </Drawer.Trigger>

        <Drawer.Content size="md">
          <Tabs.Root value={tab} onValueChange={setTab}>
            <Drawer.HeaderV2
              title="Build #1234"
              description="Triggered by push to main"
              icon="pipeline"
              tabs={[
                { label: 'Overview', value: 'overview' },
                { label: 'Logs', value: 'logs' },
                { label: 'Artifacts', value: 'artifacts', counter: 3 },
                { label: 'Tests', value: 'tests', disabled: true },
              ]}
              actions={<Button size="sm" variant="outline">Re-run</Button>}
            />
            <Drawer.Body>
              <Tabs.Content value="overview">
                <p>Overview tab content</p>
              </Tabs.Content>
              <Tabs.Content value="logs">
                <p>Logs tab content</p>
              </Tabs.Content>
              <Tabs.Content value="artifacts">
                <p>Artifacts tab content (3 items)</p>
              </Tabs.Content>
            </Drawer.Body>
          </Tabs.Root>
        </Drawer.Content>
      </Drawer.Root>
    );

}`}
/>

## Loading state

When `isLoading` is true, actions are hidden and the children (metadata) slot renders a skeleton placeholder.

<DocsPage.ComponentExample
  client:only
  code={`
    <Drawer.Root>
      <Drawer.Trigger>
        <Button>HeaderV2 Loading State</Button>
      </Drawer.Trigger>

      <Drawer.Content size="md">
        <Drawer.HeaderV2
          title="Loading Resource..."
          description="Fetching details"
          icon="repository"
          isLoading
          actions={<Button size="sm">Action</Button>}
        >
          <span>This metadata is hidden while loading</span>
        </Drawer.HeaderV2>
        <Drawer.Body>
          <p>The header hides actions and shows a skeleton for children while loading.</p>
        </Drawer.Body>
      </Drawer.Content>
    </Drawer.Root>

`}
/>
