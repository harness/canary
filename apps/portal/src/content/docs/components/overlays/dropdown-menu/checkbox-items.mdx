The `DropdownMenu` component supports checkbox items using the `DropdownMenu.CheckboxItem` component. This allows you to create items with checkboxes that can be checked or unchecked.

<DocsPage.ComponentExample
  client:only
  code={`() => {
    const [checkedItems, setCheckedItems] = React.useState({
        default: false,
        checked: true,
        disabled: false,
        checkedDisabled: true,
        withSubmenu: 'indeterminate',
        subOption1: false,
        subOption2: true
    });

    const handleCheckedChange = (itemKey, checked) => {
        setCheckedItems(prev => ({
            ...prev,
            [itemKey]: checked
        }));
    };

    return (
        <DropdownMenu.Root>
            <DropdownMenu.Trigger aria-label="options menu" asChild>
                <Button variant="ghost" iconOnly>
                    <IconV2 name="more-horizontal" />
                </Button>
            </DropdownMenu.Trigger>

            <DropdownMenu.Content>
                <DropdownMenu.Group label="Checkbox group">
                    <DropdownMenu.CheckboxItem
                        title="Default"
                        checked={checkedItems.default}
                        onCheckedChange={(checked) => handleCheckedChange('default', checked)}
                    />
                    <DropdownMenu.CheckboxItem
                        title="Checked"
                        checked={checkedItems.checked}
                        onCheckedChange={(checked) => handleCheckedChange('checked', checked)}
                    />
                    <DropdownMenu.CheckboxItem
                        title="Disabled"
                        disabled
                        checked={checkedItems.disabled}
                        onCheckedChange={(checked) => handleCheckedChange('disabled', checked)}
                    />
                    <DropdownMenu.CheckboxItem
                        title="Checked disabled"
                        description="Item description"
                        checked={checkedItems.checkedDisabled}
                        onCheckedChange={(checked) => handleCheckedChange('checkedDisabled', checked)}
                        disabled
                    />
                    <DropdownMenu.CheckboxItem
                        title="With submenu"
                        checked={checkedItems.withSubmenu}
                        onCheckedChange={(checked) => handleCheckedChange('withSubmenu', checked)}
                    >
                        <DropdownMenu.CheckboxItem
                            title="Sub Option 1"
                            checked={checkedItems.subOption1}
                            onCheckedChange={(checked) => handleCheckedChange('subOption1', checked)}
                        />
                        <DropdownMenu.CheckboxItem
                            title="Sub Option 2"
                            checked={checkedItems.subOption2}
                            onCheckedChange={(checked) => handleCheckedChange('subOption2', checked)}
                        />
                    </DropdownMenu.CheckboxItem>
                </DropdownMenu.Group>
            </DropdownMenu.Content>
        </DropdownMenu.Root>
    );

}`}/>

## Properties

### `CheckboxItem`

The `CheckboxItem` component displays a checkbox next to the item. When the user interacts with the checkbox, the
`onCheckedChange` prop is called. Setting the `checked` prop will set whether the checkbox is checked.

```typescript jsx
<DropdownMenu.CheckboxItem
  title="Item title"         // title of the item
  checked                    // [OPTIONAL] whether the checkbox is checked
  onCheckedChange={onChange} // [OPTIONAL] callback when checked state changes
  description="Description"  // [OPTIONAL] description text
  label="Label"              // [OPTIONAL] right-aligned label
  shortcut="⌘K"              // [OPTIONAL] keyboard shortcut
  checkmark                  // [OPTIONAL] show checkmark icon
  className="my-class"       // [OPTIONAL] custom class
  disabled                   // [OPTIONAL] disable the item
>
  {/* Optional nested items for submenu */}
</DropdownMenu.CheckboxItem>
```
