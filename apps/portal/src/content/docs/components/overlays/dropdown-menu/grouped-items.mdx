The `DropdownMenu` component supports grouping items together using the `DropdownMenu.Group` component. This allows you to create a structured menu with labeled sections.

<DocsPage.ComponentExample
  client:only
  code={`<DropdownMenu.Root>
    <DropdownMenu.Trigger aria-label="options menu" asChild>
        <Button variant="ghost" iconOnly>
            <IconV2 name="more-horizontal" />
        </Button>
    </DropdownMenu.Trigger>

    <DropdownMenu.Content>
        <DropdownMenu.Group label="Group label">
            <DropdownMenu.Item title="Item 1" />
            <DropdownMenu.Item title="Item 2" />
            <DropdownMenu.Item title="Item 3" />
            <DropdownMenu.Item title="Item 4" />
            <DropdownMenu.Item title="Item 5" />
        </DropdownMenu.Group>

  </DropdownMenu.Content>
</DropdownMenu.Root>`}
/>

## Properties

### `Group`

The Group component represents a labeled group of menu items.

```typescript jsx
<DropdownMenu.Group
  label="Group label"  // [OPTIONAL] label for the group
  className="my-class" // [OPTIONAL] custom class
>
  {/* Group items */}
</DropdownMenu.Group>
```
