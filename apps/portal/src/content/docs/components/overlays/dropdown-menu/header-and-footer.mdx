The `DropdownMenu` component supports header and footer sections using the `DropdownMenu.Header` and `DropdownMenu.Footer` components. This allows you to add additional content at the top or bottom of the dropdown menu.

<DocsPage.ComponentExample
  client:only
  code={`<DropdownMenu.Root>
    <DropdownMenu.Trigger aria-label="options menu" asChild>
        <Button variant="ghost" iconOnly>
            <IconV2 name="more-horizontal" />
        </Button>
    </DropdownMenu.Trigger>

    <DropdownMenu.Content>
        <DropdownMenu.Header className="grid gap-cn-3xs">
            <Text>Dropdown menu header content</Text>
            <Button>Press me</Button>
        </DropdownMenu.Header>
        <DropdownMenu.Item title="Item 1" />
        <DropdownMenu.Item title="Item 2" />
        <DropdownMenu.Item title="Item 3" />
        <DropdownMenu.Item title="Item 4" />
        <DropdownMenu.Item title="Item 5" />
        <DropdownMenu.Item title="Item 6" />
        <DropdownMenu.Item title="Item 7" />
        <DropdownMenu.Item title="Item 8" />

        <DropdownMenu.Item title="Item 10" />
        <DropdownMenu.Footer>
            <Link suffixIcon>Click me</Link>
        </DropdownMenu.Footer>

  </DropdownMenu.Content>
</DropdownMenu.Root>`}
/>

## Properties

### `Header`

The `Header` component represents a header section with a separator.

```typescript jsx
<DropdownMenu.Header
  className="my-class" // [OPTIONAL] custom class
>
  {/* Header content */}
</DropdownMenu.Header>
```
