The `DropdownMenu` component supports logo items using the `DropdownMenu.LogoItem` component. This allows you to create items with logos that can be used to represent brands or services.

<DocsPage.ComponentExample
  client:only
  code={`<DropdownMenu.Root>
    <DropdownMenu.Trigger aria-label="options menu" asChild>
        <Button variant="ghost" iconOnly>
            <IconV2 name="more-horizontal" />
        </Button>
    </DropdownMenu.Trigger>

    <DropdownMenu.Content>
        <DropdownMenu.LogoItem logo="gitlab" title="With logo" original={false} />
        <DropdownMenu.LogoItem logo="gitlab" title="With original logo" />
        <DropdownMenu.LogoItem logo="gitlab" title="With logo and description" description="Item description" />

  </DropdownMenu.Content>
</DropdownMenu.Root>`}
/>

## Properties

### `LogoItem`

The `LogoItem` component is a specialized item that displays a logo.

```typescript jsx
<DropdownMenu.LogoItem
  logo="gitlab"             // logo name
  title="Item title"        // title of the item
  original                  // [OPTIONAL] use original logo colors
  description="Description" // [OPTIONAL] description text
  label="Label"             // [OPTIONAL] right-aligned label
  shortcut="⌘K"             // [OPTIONAL] keyboard shortcut
  checkmark                 // [OPTIONAL] show checkmark icon
  className="my-class"      // [OPTIONAL] custom class
  disabled                  // [OPTIONAL] disable the item
  onSelect={onSelect}       // [OPTIONAL] event handler
>
  {/* Optional nested items for submenu */}
</DropdownMenu.LogoItem>
```
