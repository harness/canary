The `Popover` component provides a way to create floating overlays that display rich content in a popup. It's suited to menus, forms, or any content that needs to appear above other elements without disrupting the page flow.

It can be composed with subcomponents — `Popover.Root`, `Popover.Trigger`, `Popover.Content`, and `Popover.Anchor` — for a structured, customizable interface. `Popover.Content` supports built-in `title`, `description`, and `linkProps` for common patterns, while also allowing custom content through children.

<DocsPage.ComponentExample
  client:only
  code={`<Popover.Root>
    <Popover.Trigger asChild>
        <Button variant="outline">
            Open Popover
        </Button>
    </Popover.Trigger>

    <Popover.Content
        title="Settings"
        description="Manage your account settings and preferences"
    >
        <div className="grid gap-cn-sm mt-cn-sm">
            <Button variant="outline" size="sm">Profile</Button>
            <Button variant="outline" size="sm">Billing</Button>
            <Button variant="outline" size="sm">Notifications</Button>
        </div>
    </Popover.Content>

</Popover.Root>`}
/>

### Hover trigger popover

Set `triggerType` to `hover` on the shorthand `Popover` to open on hover instead of click. You can also customize the hover delay and close delay.

### Controlled popover

You can control the open state of the popover programmatically.

<DocsPage.ComponentExample
  client:only
  code={`() => {
    const [open, setOpen] = React.useState(false);

    return (
        <div className="flex gap-cn-md items-center">
            <Popover.Root open={open} onOpenChange={setOpen} modal={true}>
                <Popover.Trigger asChild>
                    <Button variant="outline">
                        {open ? 'Close' : 'Open'} Popover
                    </Button>
                </Popover.Trigger>

                <Popover.Content
                    title="Controlled Popover"
                    description="This popover's state is controlled by the parent component."
                >
                    <Button
                        variant="outline"
                        size="sm"
                        className="mt-cn-sm"
                        onClick={() => setOpen(false)}
                    >
                        Close from inside
                    </Button>
                </Popover.Content>
            </Popover.Root>

            <Button
                variant="ghost"
                size="sm"
                onClick={() => setOpen(!open)}
            >
                Toggle from outside
            </Button>
        </div>
    );

}`}
/>

### Using anchor

The `Popover.Anchor` component allows you to position the popover relative to a different element than the trigger.

<DocsPage.ComponentExample
  client:only
  code={`() => {
  const [open, setOpen] = React.useState(false);

    return (
      <Popover.Root open={open} onOpenChange={setOpen}>
        <Popover.Anchor>
          <div className="p-cn-md border rounded-cn-3 cursor-pointer" onClick={() => setOpen(!open)}>
            <Text>I'm the anchor element</Text>
          </div>
        </Popover.Anchor>
        <Popover.Content
            title="Anchored Popover"
            description="Click the box to toggle this popover."
        />
      </Popover.Root>
    )

}`}
/>

## Anatomy

`Popover` offers two APIs. Compose the parts for full control, or use the shorthand `Popover` component for the common case.

```typescript jsx
<Popover.Root>
  <Popover.Trigger />
  <Popover.Anchor />
  <Popover.Content />
</Popover.Root>

// or the shorthand

<Popover
  title="Popover Title"
  description="Popover description"
  content="Popover content"
>
  <Button>Trigger</Button>
</Popover>
```

- **`Popover.Root`** — the container; controls open state (`open` / `defaultOpen` / `onOpenChange`) and modality (`modal`). Built directly on Radix Popover.
- **`Popover.Trigger`** — the element that opens the popover; use `asChild` to render your own button.
- **`Popover.Anchor`** — optional; positions the popover against a different element than the trigger.
- **`Popover.Content`** — the floating panel, with built-in `title`, `description`, and `linkProps`, plus positioning props (`side`, `align`, `sideOffset`, `alignOffset`) and children for custom content.
- **`Popover`** (shorthand) — a single component that wraps your children as the trigger and takes `content` plus the content props. This is the only API that offers hover triggering (`triggerType`, `hoverDelay`, `closeDelay`); it does not accept `modal`.

## Best practices

{/* TODO: editorial — please review against product guidance. */}

**Do**

- Use the shorthand `Popover` for simple title/description/link popovers; reach for the composed parts when you need custom content or an anchor.
- Keep popover content concise — it's a supplement, not a page.
- Set `modal` on `Popover.Root` when the popover requires the user's full attention before returning to the page.

**Don't**

- Don't put critical, non-recoverable actions inside a popover that dismisses on outside click.
- Don't rely on hover triggering for essential content — it isn't available on touch devices and is harder to reach.

## Content

{/* TODO: editorial — please review against product guidance. */}

- Write the `title` as a short noun phrase and the `description` as one or two supporting sentences.
- Give `linkProps.text` a descriptive label ("View documentation"), not "click here".

## Accessibility

### Keyboard

- Built on Radix Popover: the trigger opens on Enter / Space, Escape closes the popover, and focus behavior follows Radix conventions.

### Labeling

- The content renders with `role="dialog"` and the trigger exposes `aria-expanded` / `aria-haspopup`.

<Aside title="Icon-only triggers">
  The `Trigger` renders as a `button` by default. Include descriptive text so assistive technologies announce it with context. If the child is solely an icon, provide an `aria-label` or a visually hidden label.

```typescript jsx
<Popover.Trigger aria-label="help information">
  <IconV2 name="help-circle" />
</Popover.Trigger>
```

Or

```typescript jsx
<Popover.Trigger>
  <IconV2 name="help-circle" />
  <span className="sr-only">Help information</span>
</Popover.Trigger>
```

</Aside>

### Focus & states

- Set `modal` on `Popover.Root` to trap focus and hide outside content from screen readers while the popover is open. The shorthand `Popover` is always non-modal (it doesn't accept `modal`) and deliberately keeps focus on the trigger rather than moving it into the content on open.
