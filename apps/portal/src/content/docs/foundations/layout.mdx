Effective layouts are essential for creating intuitive, readable user interfaces. This guide covers the key layout components and principles used throughout the Harness design system.

## Core Layout Components

Harness provides two primary components for constructing layouts:

1. <span style="font-weight: 600">Layout Component</span> - A collection of
   flexible primitives for building layouts with Flex, Grid, Horizontal, and
   Vertical arrangements.
2. <span style="font-weight: 600">Spacer Component</span> - A utility for adding
   consistent vertical spacing between elements.

<Aside>
  Whenever possible, use Layout components with the `gap` property instead of
  Spacer components. The Spacer component is primarily useful for specific cases
  where gaps cannot be used.
</Aside>

## Spacing

Consistent spacing is critical for creating visually balanced layouts. Use the `gap` property on Layout components or the `Spacer` component when needed.

> <span style="font-weight: 600">Important:</span> To utilize the `gap`
> property, you must use the Layout components (`Layout.Flex` or `Layout.Grid`).
> Regular HTML elements or non-Layout components do not support the standardized
> `gap` property from the Harness design system.

## Best Practices

<ol className="list-decimal pl-cn-xl space-y-cn-md">
  <li>
    <Text variant="body-strong">
      Use Layout Components Instead of Raw Flex/Grid
    </Text>
    <Text variant="body-normal" className="mt-cn-3xs">
      The Layout components provide consistent props and behavior across your
      application
    </Text>
  </li>

<li>
  <Text variant="body-strong">Prefer Gap Over Spacer</Text>
  <Text variant="body-normal" className="mt-cn-3xs">
    Use the `gap` property on Layout components rather than inserting Spacer
    components between items
  </Text>
</li>

<li>
  <Text variant="body-strong">Responsive Considerations</Text>
  <Text variant="body-normal" className="mt-cn-3xs">
    For complex responsive layouts, use the built-in responsive options or
    combine with media queries
  </Text>
</li>

<li>
  <Text variant="body-strong">Grid vs. Flex</Text>
  <ul className="list-disc pl-cn-xl mt-cn-3xs space-y-cn-3xs">
    <li>
      <Text variant="body-normal">
        Use Grid for two-dimensional layouts with rows and columns
      </Text>
    </li>
    <li>
      <Text variant="body-normal">
        Use Flex for one-dimensional layouts (either row or column)
      </Text>
    </li>
  </ul>
</li>

  <li>
    <Text variant="body-strong">Combine Layout Components</Text>
    <Text variant="body-normal" className="mt-cn-3xs">
      Nest Layout components to create complex interface structures
    </Text>
  </li>
</ol>

## Layout Component API

```typescript
// Flex component
<Layout.Flex
  direction="row" | "column"
  align="start" | "center" | "end" | "stretch" | "baseline"
  justify="start" | "center" | "end" | "between" | "around" | "evenly"
  wrap="nowrap" | "wrap" | "wrap-reverse"
  gap="none" | "4xs" | "3xs" | "2xs" | "xs" | "sm" | "md" | "lg" | "xl" | "2xl" | "3xl" | "4xl"
  className="custom-class"
/>

// Grid component
<Layout.Grid
  columns="1fr 2fr" | {number}
  rows="auto 1fr" | {number}
  align="start" | "center" | "end" | "stretch" | "baseline"
  justify="start" | "center" | "end" | "between" | "around" | "evenly"
  gap="none" | "4xs" | "3xs" | "2xs" | "xs" | "sm" | "md" | "lg" | "xl" | "2xl" | "3xl" | "4xl"
  className="custom-class"
/>

// Horizontal component (pre-configured Flex)
<Layout.Horizontal
  align="start" | "center" | "end" | "stretch" | "baseline"
  justify="start" | "center" | "end" | "between" | "around" | "evenly"
  gap="none" | "4xs" | "3xs" | "2xs" | "xs" | "sm" | "md" | "lg" | "xl" | "2xl" | "3xl" | "4xl"
  className="custom-class"
/>

// Vertical component (pre-configured Flex)
<Layout.Vertical
  align="start" | "center" | "end" | "stretch" | "baseline"
  justify="start" | "center" | "end" | "between" | "around" | "evenly"
  gap="none" | "4xs" | "3xs" | "2xs" | "xs" | "sm" | "md" | "lg" | "xl" | "2xl" | "3xl" | "4xl"
  className="custom-class"
/>
```
