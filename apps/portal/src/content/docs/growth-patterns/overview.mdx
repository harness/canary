PLG patterns document components and patterns used for driving user growth — onboarding flows, in-app promotional messages, and other patterns that drive adoption and activation.

These patterns and components should not be used for general UI design; the Components section above is appropriate for this.

- [**Single Pane Stepper**](/growth-patterns/single-pane-stepper) — single-column guided flow with card-based navigation
- [**Dual Pane Stepper**](/growth-patterns/dual-pane-stepper) — full-page guided flow with resizable dual panes
- [**Growth Box [WIP]**](/growth-patterns/growth-box) — in-app upgrade and limit prompts

New patterns will be added here as the design system documents more growth-oriented compositions.
