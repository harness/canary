title: Page Layouts
description: Common page-level layout patterns built with the Harness layout components
---

Page layouts combine the [layout components](/foundations/layout/) into reusable page-level structures. Use these patterns as starting points for new pages. The examples are simplified mockups; the product component for each pattern is named in its description.

- [Standard Page](/patterns/page-layouts/standard-page/)
- [Page with Section Menu](/patterns/page-layouts/page-with-section-menu/)
- [Main and Side Columns](/patterns/page-layouts/main-and-side-columns/)
- [Resizable Split](/patterns/page-layouts/resizable-split/)
- [Dashboard Card Layout](/patterns/page-layouts/dashboard-card-layout/)

The app sidebar and the collapsed AI chat rail in the examples are boilerplate, rebuilt from the production shell and shown disabled for context only.

:::note
The examples are drawn on a 1440 × 900 screen and scaled down to fit the page, so they appear smaller than 100%. Sizes, spacing and text in the examples are reduced by the same percentage; the real values are listed in the Usage tab of each pattern.
:::
