## Anatomy

1. **Page header.** Breadcrumb, title, description and underlined tabs, shared with the other page layouts.
2. **Main column.** Takes the remaining width (`1fr`) and holds the primary content: files, a conversation or a form. Give it `min-w-0` so long content can shrink instead of overflowing.
3. **Side column.** A fixed width, 272px for a summary and 334px for a richer panel with reviewers and labels. It holds metadata and quick actions, never the primary task.
4. **Gap.** Leave a gap of 24px (`xl`) between the columns, or pad the main column on its right.

## Guidelines

- Use `columnWidths="1fr 272px"` or `columnWidths="minmax(calc(100% - 334px), 1fr) 334px"` so only the main column flexes.
- Keep the side column short. If it is longer than the main column, move some of it into the main column or into a tab.
- Order the side column by importance, and separate groups with a divider.
- Below the tablet breakpoint, stack the side column under the main column.
- For a layout whose columns resize, use [resizable split](/patterns/page-layouts/resizable-split/).
