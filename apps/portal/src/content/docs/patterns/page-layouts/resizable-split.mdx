Two panels separated by a drag handle so people can adjust the space between them. Use it when both panels hold working content and the right balance depends on the task, such as an editor beside its results. In product code this is `Resizable.PanelGroup`, `Resizable.Panel` and `Resizable.Handle`.

A governance rule page inside the full application shell. The left panel holds the YAML editor and the right panel runs the rule against sample commits. The group sits in a bordered frame and starts at a 40 / 60 split.

The app sidebar and the collapsed AI chat rail are boilerplate, rebuilt from the production shell and shown disabled for context only.

## Anatomy

1. **Panel group.** `Resizable.PanelGroup` with `direction="horizontal"` for side-by-side panels. It needs a height, such as a fixed `height`, `min-h-[600px]` or a flex parent with `h-full`, otherwise the panels collapse.
2. **Panels.** Each `Resizable.Panel` takes a `defaultSize` and a `minSize`, both as percentages. The sizes of all panels in a group should add up to 100.
3. **Handle.** `Resizable.Handle` between panels. Add `withHandle` to show a grip so the drag target is easy to find.
4. **Panel content.** Each panel fills its area and scrolls on its own. Give panels `min-h-0` and `overflow-auto` so long content scrolls inside the panel and not the page.

## Guidelines

- Always set `minSize` on every panel, typically 25 to 35, so neither panel can be dragged shut.
- Give the panel people work in most the larger share: 55 / 45 for a builder and its output, 40 / 60 for an editor beside results.
- Use `withHandle` when the groups are framed or dense. Use the plain handle when a border already separates the panels.
- Give each panel its own header with a title and actions, so the split reads as two tools rather than one blank area.
- Only split when both panels are useful at the same time. For primary content with supporting details, use [main and side columns](/patterns/page-layouts/main-and-side-columns/).
- Below the tablet breakpoint, stack the panels or switch to tabs.
