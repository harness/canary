## Anatomy

1. **Sidebar.** `Sidebar.Root` with a header (the project or account switcher), content groups of `Sidebar.Item`, and a footer for alerts, help and the user. It is 240px wide when expanded and collapses to icons.
2. **Content area.** `Sidebar.Inset` holds the page. It scrolls on its own, so the sidebar stays in place.
3. **Page padding.** The content uses `px-cn-xl`, `pt-cn-md` and `pb-cn-xl`. Page layouts such as the standard page add their own header and content inside it.

## Guidelines

- Put the shell at the root of the app and render every page inside `Sidebar.Inset`. Do not rebuild the sidebar per page.
- Mark the current area with the `active` prop on `Sidebar.Item`.
- Keep the footer for global items: alerts, help and the account menu.
- Below the tablet breakpoint, collapse the sidebar by default.
- For secondary navigation inside a section, use [page with section menu](/patterns/page-layouts/page-with-section-menu/).
