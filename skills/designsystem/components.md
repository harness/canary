# Components

Index of components that have a contract. Open only the one you need. A component not listed has no contract: say so, then read its source.

| Component | Export | Use for |
| --- | --- | --- |
| [Button Component](button/SKILL.md) | `Button` | The library's only guaranteed-actionable control — seven emphasis variants, four semantic themes, five sizes, icon-only mode, and automatic loading from a promise-returning onClick |
| [Drawer Component](drawer/SKILL.md) | `Drawer` | Side panel for creating, editing, or inspecting one entity over the current page — Root, Content, Header, Body and Footer |
| [Layout Component](layout/SKILL.md) | `Layout` | Arrangement primitives — Horizontal, Vertical, Flex and Grid — and the only sanctioned way to put tokenised space between elements |
| [StatusBadge Component](status-badge/SKILL.md) | `StatusBadge` | Status indicator badge with muted, success, warning, danger, info, merged, and risk themes |
| [Tag Component](tag/SKILL.md) | `Tag` | Decorative-colour label for stable attributes, with optional icon, split label/value pair, and dismiss action |

Page and composition patterns: see [rules.md](rules.md).
