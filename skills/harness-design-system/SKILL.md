# Harness design system

Before writing code, read [rules.md](./rules.md). Then:

- [components.md](./components.md): which components have a guide. Each guide lives in its own folder here, for example [button/SKILL.md](./button/SKILL.md).
- [patterns/](./rules.md#patterns): page and composition patterns, listed in rules.md.
- [foundations/](./rules.md#foundations): colour, spacing, typography, shadows, accessibility and app setup, listed in rules.md.
